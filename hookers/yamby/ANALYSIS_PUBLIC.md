# Yamby 设置项与授权机制技术分析报告（开源分享版）

## 1. 概述
- **目标类型**：Android 影视客户端 (Kotlin + AndroidX Preference + Compose)
- **分析版本**：v2.1.0
- **核心难点**：nmmp (dex2c) 原生化保护、混淆字符类名、UI Preference 控件独立判定

---

## 2. 授权状态在 UI 层的呈现机制
在 Android 传统与混淆应用中，常见一种设计：
- 核心网络与存储层记录了购买凭据（如本地 Key-Value 缓存）。
- 界面控件（如 `PreferenceViewHolder`）内部封装了独立的装饰器模式，在 `onBindViewHolder` 时依据控件自有的布尔方法判断是否渲染为禁用状态（例如置换为灰色背景 drawable 或调用 `setEnabled(false)`）。

若仅对存储层（如 SharedPreferences / MMKV）打桩，而未在 UI 控件渲染时介入修改其入参或视图装饰器，界面层将继续保持为灰色的禁用状态。

---

## 3. 解除 UI 置灰的技术方案
1. **多态与接口识别**：通过 Dalvik 字节码扫描定位实现自定义装饰接口的 Preference 类。
2. **切入点设计**：
   - 拦截包含 `(boolean, Context, ...)` 签名的视图渲染入口，强制前置修改首个布尔参数为 `true`。
   - 对控件自有的状态判定函数实施常量返回。
   - 保证底层与表现层数据的一致性。

---

## 4. 高级媒体与弹幕特权预置
1. **弹幕过滤上限与色彩特权**：拦截本地偏好存取层，扩展弹幕屏蔽规则容量限制并放行个性化彩色弹幕。
2. **硬解码与片头智能预置**：预置底层播放器硬件解码参数，开启章节与片头自适应跳过。
